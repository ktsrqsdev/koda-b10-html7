# Simple Calculator UI

This is a simple calculator design made with HTML and CSS. I made this project to practice my HTML structure and CSS styling.

## Features

- Calculator display
- Number buttons from 0 to 9
- Basic math operation buttons
- Memory buttons
- Clear and delete buttons
- Hover effect on buttons
- Different colors for each button type

## Built With

- HTML
- CSS

## What I Learned

While making this project, I practiced:

- Using CSS Grid to arrange the calculator buttons
- Using CSS variables for colors and fonts
- Styling buttons with background colors, shadows, and border radius
- Using `:hover` and `:nth-child()` to style specific buttons


> This project is currently a calculator UI. The buttons are not functional yet because I have not added JavaScript.
